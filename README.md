# GW-Reinfickmaschine (gw1-teambuilder)

Planer für Guild Wars 1. Klasse wählen, Build übernehmen oder anpassen, Gebiet oder Ziel wählen. Die Helden kommen automatisch dazu, mit Ausrüstung, Schadensrechnung und Abläufen für Elitegebiete, Rush-Routen und Farmspots.

Statische Seite ohne Server, läuft über GitHub Pages: https://lkz481.github.io/gw1-teambuilder/

## Quellen
- Fertigkeitswerte, Bilder, Heldenliste, Gebietsdaten, Laufanleitungen: [Guild Wars Wiki](https://wiki.guildwars.com)
- Deutsche Namen und Beschreibungen: [guildwiki.de](https://www.guildwiki.de)
- Builds, Teams, Ausrüstung, Farm-Abläufe: [PvX Wiki](https://gwpvx.fandom.com) (inoffiziell)
